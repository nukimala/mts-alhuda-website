# Checklist Revisi Laporan SQA

Target versi: **v2**

## Ringkasan eksekutif

- [ ] Tulis ulang ringkasan sesuai scope baru.
- [ ] Hapus klaim hasil lama yang tidak diuji ulang.
- [ ] Sebutkan build/commit yang diuji.
- [ ] Sebutkan tanggal dan lingkungan uji.

## Arsitektur

- [ ] Diagram D-01 dimasukkan.
- [ ] Diagram D-06 ERD dimasukkan.
- [ ] Diagram D-07 use case dimasukkan.
- [ ] Diagram D-11 SDLC/QA dimasukkan.
- [ ] Diagram D-12 deployment dimasukkan.
- [ ] Tidak ada klaim Firestore untuk data akademik.

## Metodologi

- [ ] Level pengujian dijelaskan.
- [ ] Lingkungan lokal/staging dijelaskan.
- [ ] Data uji dijelaskan.
- [ ] Tools dijelaskan.
- [ ] Peran tim dijelaskan.

## Hasil

- [ ] Tabel hasil lama direset ke `Not Executed`.
- [ ] Tabel hasil baru diisi dari eksekusi aktual.
- [ ] Pass/fail/blocked dihitung ulang.
- [ ] Coverage per modul ditulis.
- [ ] Defect summary per severity ditulis.
- [ ] Bukti dilampirkan atau ditautkan.

## Temuan dan kesimpulan

- [ ] Temuan lama ditandai `Closed - Out of Scope` jika tidak relevan.
- [ ] Temuan baru punya ID, severity, status.
- [ ] Rekomendasi ditulis.
- [ ] Kesimpulan tidak melebih-lebihkan.
- [ ] Keterbatasan pengujian ditulis.
- [ ] Rencana perbaikan/tindak lanjut ditulis.

## Administratif

- [ ] Versi dan riwayat revisi.
- [ ] Daftar gambar diperbarui.
- [ ] Nomor halaman dan daftar isi diperbarui.
- [ ] Approval UAT.
- [ ] PDF lama diarsipkan.
