# Hasil Ekspor Diagram

Folder ini menyimpan hasil ekspor diagram untuk dimasukkan ke dokumen SQA.

## Format

| Kebutuhan | Format |
|---|---|
| Word/PDF laporan | PNG 300 dpi |
| Web/Markdown | SVG |
| Presentasi | PNG 150–200 dpi |

## Penamaan

Gunakan ID yang sama dengan source:

## Checklist sebelum dipakai di laporan

- [ ] Teks terbaca pada ukuran cetak.
- [ ] Tidak ada teks terpotong.
- [ ] Istilah konsisten dengan dokumen.
- [ ] Tidak ada data sensitif.
- [ ] Nomor gambar sesuai daftar gambar.
- [ ] Versi dan tanggal diagram benar.
- [ ] Source diagram ada di `../DIAGRAM.md`.
